... Descreva as tags <b>, <i>, <sup>, <sub>, <strong>, <em>, <blockquote> e <q>. Crie
uma página Web que contenha exemplos de utilização dessas tags.

<b> -
Destacaa uma parte do texto, geralmente em negrito.

<i> -
ssim como <b>, <i> tambem destaca partes do texto, como é exibida no formato ítalico, <i> é utilizado para destacar termos tecnicos, palavras em outros idiomas etc.

<sup>
Indica que o texto ficara sobreescrito, ex: expeontes numa potência.

<sub>
O oposto de "<sup>", fica subscrito na linha, ex: formulas químicas.

<strong> - 
Diferente de "<b>", <strong> tem importância semântica, se apresenta em negrito e é utilizada para indicar conteudo importante.

<em> -
Assim como "<strong>" e diferente de "<i>", <em> tem importância semântica, também se apresenta em italico e é utilizada para indicar conteudo importante.

<blockquote> - 
Utilizada para fazer citações longas. O paragrafo normalmente fica recuado na exibição. Para citações curtas, utilizar <q>.

<q> - 
Utilizada para fazer citações curtas. O navegador tende a incluir aspas.
